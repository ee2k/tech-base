# LaTeX geometry

||||
|-|-|-|
| $\Large \angle ABC$ |&emsp;&emsp;| $\Large \verb!\angle ABC!$ |
| $\Large \measuredangle ABC$ || $\Large \verb!\measuredangle ABC!$ |
| $\Large AB \perp CD$ || $\Large \verb!AB \perp CD!$ |
| $\Large AB \parallel CD$ || $\Large \verb!AB \parallel CD!$ |
| $\Large \triangle ABC$ || $\Large \verb!\triangle ABC!$ |
| $\Large \square ABCD$ || $\Large \verb!\square ABCD!$ |
| $\Large 90^\circ$ || $\Large \verb!90^\circ!$ |
| $\Large \overline{AB}$ || $\Large \verb!\overline{AB}!$ |
| $\Large \vec{AB}$ || $\Large \verb!\vec{AB}!$ |

Congruence (`\cong`) is listed in [logic-and-proofs](../logic-and-proofs/);
`\perp` also denotes independence in [probability](../probability/).
Overlines and vector accents are in [accents](../accents/).
