# LaTeX logic and proofs

## Quantifiers and connectives

||||
|-|-|-|
| $\Large \forall x$ |&emsp;&emsp;| $\Large \verb!\forall x!$ (for all) |
| $\Large \exists x$ || $\Large \verb!\exists x!$ (there exists) |
| $\Large \nexists x$ || $\Large \verb!\nexists x!$ (does not exist) |
| $\Large \neg p$ || $\Large \verb!\neg p!$ (not; also `\lnot`) |
| $\Large p \land q$ || $\Large \verb!p \land q!$ (and) |
| $\Large p \lor q$ || $\Large \verb!p \lor q!$ (or) |
| $\Large p \implies q$ || $\Large \verb!p \implies q!$ (implies) |
| $\Large p \iff q$ || $\Large \verb!p \iff q!$ (if and only if) |

`\iff` is the logical biconditional (`⟺`); `\leftrightarrow` is only a
bidirectional arrow and lives in [arrows](../arrows/). `\therefore`
("therefore") is a distinct symbol from `\implies`.

||||
|-|-|-|

## Proof notation

||||
|-|-|-|
| $\Large \vdash$ |&emsp;&emsp;| $\Large \verb!\vdash!$ (provable from) |
| $\Large \models$ || $\Large \verb!\models!$ (models / satisfies) |
| $\Large \therefore$ || $\Large \verb!\therefore!$ |
| $\Large \because$ || $\Large \verb!\because!$ |
| $\Large \top$ || $\Large \verb!\top!$ (true) |
| $\Large \bot$ || $\Large \verb!\bot!$ (false; also `\perp`) |
| $\Large x \longmapsto f(x)$ || $\Large \verb!x \longmapsto f(x)!$ (maps to) |

Order and comparison relations are in [relations](../relations/); set
operations are in [set-theory](../set-theory/).
