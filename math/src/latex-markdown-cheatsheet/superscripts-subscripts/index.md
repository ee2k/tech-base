|-|-|-|

| $\Large x^{123}$ || $\Large \verb!x^{123}!$ |
| $\Large x_{ijk}$ || $\Large \verb!x_{ijk}!$ |
| $\Large x^{a}_{b}$ || $\Large \verb!x^{a}_{b}!$ |
| $\Large x^{i_j}$ || $\Large \verb!x^{i_j}!$ (braces group multi-token scripts) |
