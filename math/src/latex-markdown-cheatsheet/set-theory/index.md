# LaTeX set theory

||||
|-|-|-|
| $\Large x \in A$ |&emsp;&emsp;| $\Large \verb!x \in A!$ |
| $\Large A \ni x$ || $\Large \verb!A \ni x!$ |
| $\Large A \subseteq B$ || $\Large \verb!A \subseteq B!$ |
| $\Large A \subsetneq B$ || $\Large \verb!A \subsetneq B!$ |
| $\Large A \nsubseteq B$ || $\Large \verb!A \nsubseteq B!$ |
| $\Large A \cup B$ || $\Large \verb!A \cup B!$ |
| $\Large A \cap B$ || $\Large \verb!A \cap B!$ |
| $\Large A \setminus B$ || $\Large \verb!A \setminus B!$ |
| $\Large \bigcup_{i} A_i$ || $\Large \verb!\bigcup_{i} A_i!$ |
| $\Large \bigcap_{i} A_i$ || $\Large \verb!\bigcap_{i} A_i!$ |
| $\Large \emptyset$ || $\Large \verb!\emptyset!$ |
| $\Large \varnothing$ || $\Large \verb!\varnothing!$ |
| $\Large \mathcal{P}(A)$ || $\Large \verb!\mathcal{P}(A)!$ (power set) |
| $\Large A \times B$ || $\Large \verb!A \times B!$ (cartesian product) |
| $\Large \mathbb{N},\mathbb{Z},\mathbb{Q},\mathbb{R},\mathbb{C}$ || $\Large \verb!\mathbb{N}, \mathbb{Z}, ...!$ |

Number-set blackboard bold is a font command — see
[fonts-and-styles](../fonts-and-styles/). `\setminus` has its canonical
home here and is cross-linked from [logic-and-proofs](../logic-and-proofs/).
