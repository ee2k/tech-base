Use `\operatorname{...}` for multi-letter names so they are not italicised;
`\operatorname*{...}` puts limits above/below like `\lim`. Limits and `\limsup`
are in [big-operators](../big-operators/). Probability-specific
notation is in [probability](../probability/).
