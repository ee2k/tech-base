# LaTeX combinatorics and number theory

||||
|-|-|-|
| $\Large \binom{n}{k}$ |&emsp;&emsp;| $\Large \verb!\binom{n}{k}!$ |
| $\Large \dbinom{n}{k}$ || $\Large \verb!\dbinom{n}{k}!$ |
| $\Large \tbinom{n}{k}$ || $\Large \verb!\tbinom{n}{k}!$ |
| $\Large n!$ || $\Large \verb!n!!$ |
| $\Large a \bmod n$ || $\Large \verb!a \bmod n!$ |
| $\Large a \pmod{n}$ || $\Large \verb!a \pmod{n}!$ |
| $\Large \gcd(a,b)$ || $\Large \verb!\gcd(a,b)!$ |
| $\Large \lfloor x \rfloor$ || $\Large \verb!\lfloor x \rfloor!$ |
| $\Large \lceil x \rceil$ || $\Large \verb!\lceil x \rceil!$ |

`\pmod{n}` adds parentheses and spacing automatically; `\bmod` is the binary
operator form. Floor/ceiling delimiters are documented in
[delimiters](../delimiters/).
