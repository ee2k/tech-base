# LaTeX cases (piecewise functions)

$$
f(x)=
\begin{cases}
x^2 & x \geq 0\\
-x & x < 0
\end{cases}
$$

```latex
f(x)=
\begin{cases}
x^2 & x \geq 0\\
-x & x < 0
\end{cases}
```

`&` separates the expression from its condition; `\\` starts a new line. For
other multi-line layouts see
[multiline-environments](../multiline-environments/).
