# LaTeX big operators

||||
|-|-|-|
| $\Large \sum_{i=1}^n$ |&emsp;&emsp;| $\Large \verb!\sum_{i=1}^n!$ |
| $\Large \prod_{i=1}^n$ || $\Large \verb!\prod_{i=1}^n!$ |
| $\Large \int_a^b$ || $\Large \verb!\int_a^b!$ |
| $\Large \iint$ || $\Large \verb!\iint!$ |
| $\Large \iiint$ || $\Large \verb!\iiint!$ |
| $\Large \oint$ || $\Large \verb!\oint!$ |
| $\Large \lim_{x\to0}$ || $\Large \verb!\lim_{x\to0}!$ |
| $\Large \limsup_{n}$ || $\Large \verb!\limsup_{n}!$ |
| $\Large \liminf_{n}$ || $\Large \verb!\liminf_{n}!$ |
| $\Large \partial$ || $\Large \verb!\partial!$ |
| $\Large \nabla$ || $\Large \verb!\nabla!$ |
| $\Large \sum\limits_{i}$ || $\Large \verb!\sum\limits_{i}!$ |
| $\Large \displaystyle\sum_{i=1}^n$ || $\Large \verb!\displaystyle\sum_{i=1}^n!$ |

`\limits` forces limits above/below even in inline math; `\displaystyle`
switches the whole expression to display style. Sub/superscript syntax is in
[superscripts-subscripts](../superscripts-subscripts/), and `\to` is in
[arrows](../arrows/).
