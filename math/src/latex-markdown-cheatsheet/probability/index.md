# LaTeX probability

||||
|-|-|-|
| $\Large P(A)$ |&emsp;&emsp;| $\Large \verb!P(A)!$ |
| $\Large \Pr(A)$ || $\Large \verb!\Pr(A)!$ |
| $\Large \mathbb{P}(A)$ || $\Large \verb!\mathbb{P}(A)!$ |
| $\Large P(A\mid B)$ || $\Large \verb!P(A\mid B)!$ |
| $\Large \mathbb{E}[X]$ || $\Large \verb!\mathbb{E}[X]!$ |
| $\Large \operatorname{Var}(X)$ || $\Large \verb!\operatorname{Var}(X)!$ |
| $\Large \operatorname{Cov}(X,Y)$ || $\Large \verb!\operatorname{Cov}(X,Y)!$ |
| $\Large X \perp Y$ || $\Large \verb!X \perp Y!$ (independent) |

`\mid` gives the conditional bar with proper spacing. `\mathbb` and
`\operatorname` are documented in [fonts-and-styles](../fonts-and-styles/)
and [functions-and-operators](../functions-and-operators/). `\perp` also
means perpendicular in [geometry](../geometry/).
