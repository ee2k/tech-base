# LaTeX text size

$$\tiny \verb!\tiny!$$

$$\scriptsize \verb!\scriptsize!$$

$$\footnotesize \verb!\footnotesize!$$

$$\small \verb!\small!$$

$$\normalsize \verb!\normalsize!$$

$$\large \verb!\large!$$

$$\Large \verb!\Large!$$

$$\LARGE \verb!\LARGE!$$

$$\huge \verb!\huge!$$

$$\Huge \verb!\Huge!$$

These commands change **text size**. For scaling brackets/parentheses see
[delimiters](../delimiters/); for `\displaystyle` in fractions and
sums see [fractions-and-radicals](../fractions-and-radicals/) and
[big-operators](../big-operators/).
