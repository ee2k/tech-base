LaTeX text, spacing and escaping

Text inside math
if x>0\Large \text{if } x > 0if x>0    \text{if } x > 0\Large \verb!\text{if } x > 0!\text{if } x > 0
a and b\Large a \text{ and } ba and b a \text{ and } b\Large \verb!a \text{ and } b!a \text{ and } b
20%\Large \text{20\%}20% \text{20\%}\Large \verb!\text{20\%}!\text{20\%}
dx\Large \mathrm{d}xdx \mathrm{d}x\Large \verb!\mathrm{d}x!\mathrm{d}x

\text{...} preserves spaces; adjacent math needs its own $...$ or a space inside the braces (\text{if }). For font shapes see fonts-and-styles.

Spacing
a b\Large a\,bab    a\,b\Large \verb!a\,b!a\,b (thin)
a b\Large a\:bab a\:b\Large \verb!a\:b!a\:b (medium)
a  b\Large a\;bab a\;b\Large \verb!a\;b!a\;b (thick)
a ⁣b\Large a\!bab a\b!\Large \verb!a\!b!a\b! (negative thin)
ab\Large a\quad bab a\quad b\Large \verb!a\quad b!a\quad b
ab\Large a\qquad bab a\qquad b\Large \verb!a\qquad b!a\qquad b
ab\Large a\hspace{2em}bab a\hspace{2em}b\Large \verb!a\hspace{2em}b!a\hspace{2em}b
aba \\[1em] b(extra row space) \Large \begin{gathered} a\\[1em] b \end{gathered} \qquad \Large \verb!a \\[1em] b! \quad\text{(extra row space)} ab​a \\[1em] b(extra row space)

\\[1em] is mainly used inside display math and arrays — see multiline-environments and matrices-and-arrays.

KaTeX does not support LaTeX’s \textbackslash; use \backslash as shown above. Prefer commands over pasted Unicode symbols (≤, ≈, ∝, …) so the source stays portable — see relations.
