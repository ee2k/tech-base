Tags and numbering

a=bc=d \begin{align} a &= b\\ c &= d \end{align} ac​=b=d​​
a=bc=d \begin{align} a &= b \notag \\ c &= d \tag{*} \end{align} ac​=b=d​(*)​

\notag suppresses the equation number; \tag{*} replaces it with a custom tag. Both only work in display math.

\begin{align}
a &= b \notag \\
c &= d \tag{*}
\end{align}
